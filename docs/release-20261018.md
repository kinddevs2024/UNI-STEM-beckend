# Global Olympiad release — 18 October 2026

Published to https://www.global-olimpiads.biz with the existing MongoDB, uploads and recordings preserved. The release was copied from the current production source before adding these changes; the Git commit also captures previously deployed source that had not reached this repository.

## Behavior

- School grades 5–11 and Student are valid categories. Registration records the category; existing users can choose before starting a categorized Olympiad.
- Questions, displayed prize lists and student leaderboards use the applicable category. Names are required for prizes; photos are optional uploads or HTTPS URLs.
- Attempts and results retain their original category, including legacy shared questions. Changing the profile does not change a running attempt or erase its answers.
- Normal registration starts with zero coins. Accounts created by administration or tickets default to 50; ticket-specific amounts and manual credits remain available.
- Administration supports per-category Excel templates, import and export for test, essay and mixed Olympiads.

## Existing behavior to distinguish

The separate automatic first-place coin settlement still selects one winner across the whole Olympiad. The configurable named prizes and student leaderboards are separated by class. This release does not silently reissue historical coin rewards or modify that financial policy.
